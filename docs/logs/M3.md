## 改动点

1. **迁移层**：
   - `V2__collect_watermark.sql` — `collect_watermark` 表（`PRIMARY KEY (tenant_id, target_id)`、`last_ts DATETIME(3)`、`updated_at`），`make migrate` 幂等应用（`MigrationRunner` 自动发现 `V*__*.sql`）
2. **存储层**（新增三 store，模式照抄 M2 的 ABC 三件套）：
   - `monitor_targets.py` — `MonitorTargetStore` ABC + `InMemoryMonitorTargetStore` + `MySQLMonitorTargetStore`：create（生成 `target_id = MT-%04d`，租户内递增）/ list（service/signal_type 过滤）/ get / update（patch）/ delete（软删 enabled=0）/ load_all_targets（enabled，M6 调度器用）
   - `snapshots.py` — `SnapshotStore` ABC + InMemory + MySQL：`write(tenant_id, target_id, signals, *, domain)` 把 MetricSignal（metric/value/labels）与 LogSignal（level/message/signature）分派为 `signal_snapshot` 行
   - `watermarks.py` — `WatermarkStore` ABC + InMemory + MySQL：`get` / `update`（`INSERT ... ON DUPLICATE KEY UPDATE`）
   - `__init__.py` — `Storage` 聚合加 `monitor_targets`/`snapshots`/`watermarks` 三字段；`build_storage` memory→InMemory、mysql→MySQL 分派
   - `connection.py` — 抽出 `_decode_json` helper（dict/list 直接返回，否则 `json.loads`）
3. **signature 纯函数**（M4 signature_aggregate 共享）：
   - `signature.py` — `signature(log, n_frames=3)`：有 stack_trace → `exc首行:前 + 前 n 个 frame 去括号`，无 → `message[:120]` 回退
   - `models/signal.py` — `LogSignal` 加**可选字段** `signature: str | None = None`（M1 契约允许）
4. **collectors 包**（新增）：
   - `_gateway.py` — `OutboundGateway`：`validate_url`（scheme 白名单 + BLOCKED_NETWORKS IP 字面量拦截）、`validate_headers`（明文凭据拒绝 + authorization/x-api-key 必须含 secret 引用）、`resolve_secret`（`${env:X}` 解析、`${vault:...}` 占位、支持 "Bearer ${env:X}" 内嵌替换）
   - `_http_client.py` — `SharedHttpClient`（httpx.AsyncClient：超时 `outbound_timeout_sec`、连接池 50、`follow_redirects=False`、可注入 MockTransport；`max_content_length` 参数不存在 → `request()` 返回后手动检查响应体大小抛 `AppException`）
   - `_field_mapping.py` — `FieldMapper`：`_extract_path`（点路径 + 数组索引 `value[1]`）、`_parse_ts`（ISO 字符串 / unix 秒 → 朴素 UTC）、`map_metric` / `map_log`
   - `_context.py` — `CollectContext`（`tenant_id` + 可选 `watermark_store` / `snapshot_store`；两者为 None 时 /test 模式不写库）
   - `http_metrics.py` / `http_logs.py` — `HttpMetricsCollector` / `HttpLogsCollector`：网关校验 → secret 解析 → 水位线下推 `params["start"]` → 请求 → `_extract_path(resp.json(), rows_path)` → 字段映射 → 幂等去重（metric: hash(metric|value|timestamp)；log: hash(service|signature|timestamp) + 预计算 `signature()`）→ 水位线推进 → snapshot 写入
   - `mock.py` — `MockCollector` 返回 `target["_mock_signals"]`
   - `__init__.py` — `collector_for(target, *, http, settings)` 按 `signal_type + source_type` 直接 import 分派；导出公共符号
5. **Router**：
   - `deps.py` — `get_tenant_id(request)`（`X-Tenant-Id` 头，默认 `default`）
   - `monitors.py` — `/v1/monitors` CRUD + `/test`：POST 先过 `validate_url` + `validate_headers` 再落库（201 返回 `{"target_id"}`）；GET 列表/详情（404）；PUT 变更 source_config 重新校验；DELETE 软删（204）；POST `/{id}/test` 连通性测试（CollectContext 不写库，成功返回信号样本、网关错误走 AppException 4xx、上游异常返回 `status="error"` 200 结构化错误）
   - `_app.py` lifespan — 接线 `app.state.http_client = SharedHttpClient(settings)`，finally `aclose()`
   - `api.py` — include `monitors_router`
6. **pyproject.toml**：
   - `httpx>=0.27` 从 dev 移入运行时 `dependencies`
   - 取消注释 `[project.entry-points."aiops_apm.collectors"]`（http_metrics/http_logs/mock → build；M4 registry 消费）
7. **测试**（TDD，68 新增用例 → 总数 113）：`test_gateway.py`（13，UC-3.7/3.8）、`test_signature.py`（3，UC-3.4）、`test_field_mapping.py`（7，UC-3.3/3.4）、`test_collectors.py`（9，UC-3.3/3.4/3.5/3.6，FakeHttp 注入 + InMemory watermark/snapshot）、`test_monitor_targets.py`（7，UC-3.1）、`test_snapshots.py`（4，UC-3.3/3.4）、`test_watermarks.py`（5，UC-3.5）、`test_monitors_api.py`（10，UC-3.1/3.2/3.7/3.8，TestClient + memory backend + 替换 http_client）；扩展 `test_migrations.py`（V2 断言 + 三个受影响断言更新）

## 遗留问题 / 后续注意

- **真 MySQL 的 V2 迁移与三个 MySQL store 读写未实测**（本机 MySQL 未运行）；语义由 InMemory 单测对齐覆盖，`make migrate` 待 DB 可用时补跑
- `shared_http_client` 的 `max_content_length` 修正：httpx 0.28 `AsyncClient` 无此参数，改为 `request()` 返回后检查 `len(resp.content)` 抛 `AppException(VALIDATION, "response too large")`
- 出站网关 `SECRET_REF_PATTERN` 去掉首尾锚点（`^\$\{...\}$` → `\$\{(env|vault):[^}]+\}`），支持 "Bearer ${env:X}" 内嵌引用
- `monitor_targets.py` 的 `load_all_targets` 返回注解用 `builtins.list[dict]`：方法 `list` 定义了类内同名 `list`，mypy 把裸 `list[dict]` 解析为方法类型 → 用 `builtins.list` 显式指代（mypy #11235 同类问题）
- `POST /v1/monitors/{target_id}/run`（立即执行）与调度器、并行 `asyncio.gather` + `degraded_sources` 随 M6；DNS 解析后二次校验、Vault 密钥管理随 M7
- 插件 `entry_points` 已注册（`['http_logs', 'http_metrics', 'mock']`），M4 registry 消费
