## 改动点

1. **插件 registry**（设计 §5.3）：
   - `plugins/registry.py` — `PluginRegistry`：`load`/`reload`（遍历三个 entry_points group，`build(http=..., pool=..., settings=...)` 实例化，构建新快照后一次 `MappingProxyType` **原子替换**）/ `get`（未命中抛 `AppException(PLUGIN_NOT_FOUND, f"{kind}/{name}")`）/ `list`（分组插件名）/ `register`（注入，design §5.3，测试/管理入口）。单插件加载失败 `logger.warning` 隔离不拖垮；防御第三方 `async build()`（`inspect.iscoroutine` 拒绝并告警）。
   - `GROUPS = {collector: aiops_apm.collectors, detector: aiops_apm.detectors, suppressor: aiops_apm.suppressors}`（单数 suppressor，与设计 §5.3 / `l0_suppress` 一致；Enhanced plan 骨架里的 "suppressors" 是笔误）。
   - `plugins/__init__.py` 导出 `PluginRegistry`/`GROUPS`。
2. **内置 detector**（设计 §6.4，三件套 + `build()`）：
   - `detectors/static_threshold.py` — `Operator(str, Enum)` GT/GTE/LT/LTE/RANGE；RANGE =「区间外命中」（`params["range"]` 缺省 `[threshold, threshold]`）；只处理 `MetricSignal`；`severity` 默认 warning；`labels` 透传。
   - `detectors/simple_compare.py` — `value > baseline * ratio`（ratio 默认 1.5；`baseline is not None` 判断，避免 baseline=0 被 truthy 吞掉）；基线来自 params（signal_snapshot 滚动均值留 M5 pipeline 注入）。
   - `detectors/signature_aggregate.py` — 按 signature 分组（优先用 M3 预计算 `LogSignal.signature`，缺省回退 `signature()` 纯函数）；`count >= min_count` → 1 条 `LogAnomaly(count, first_seen=min, detected_at=max)`。
3. **内置 suppressor**（设计 §6.3）：
   - `suppressors/maintenance_window.py` / `blacklist.py` — 数据从 `ctx.maintenance_windows` / `ctx.blacklist` 读取（**不碰表**；表读取加载进 ctx 属 M5 DetectionContext，写表 admin API 属 M6）。两者同时实现 `check` 单条与 `batch_check` 批量（注意：`check` 是基类抽象方法，黑名单也必须实现，Enhanced plan 骨架只给 batch_check 无法实例化——已补全）。
4. **L1 信号匹配**（Enhanced plan 骨架 + 完成标准点名）：
   - `pipeline/filter_signals.py` — `filter_signals(signals, matcher)`：`None`/`*`/`""` → 全量；str → 向后兼容（metric 名 / log level）；dict → 结构化 matcher（`signal_type` 分派：metric→metric/labels/service；log→level/service；空值/缺失视为通配）；`_labels_match` 子集匹配；其余类型 → `[]`。`labels: null` 视为空通配（review 修正）。
5. **Router**（UC-4.1/4.2，用户确认纳入）：
   - `router/plugins.py` — `GET /v1/plugins` 返回三组插件名；`POST /v1/plugins/reload` 重新扫 entry_points 原子替换后返回更新列表（`asyncio.to_thread` 放线程执行，避免第三方插件 build 阻塞事件循环）。
   - `_app.py` lifespan — 接线 `app.state.registry = PluginRegistry().load(http=..., pool=storage.pool, settings=...)`；`/ready` 的 plugins 由 False → True（200 ready）。
   - `_status_for_code` 补 `PLUGIN_NOT_FOUND → 404`。
   - `router/api.py` include plugins router。
6. **pyproject.toml** — 放开 `[project.entry-points."aiops_apm.detectors"]`（static_threshold / simple_compare / signature_aggregate）与 `[project.entry-points."aiops_apm.suppressors"]`（maintenance_window / blacklist）；改后 `.venv/bin/pip install -e ".[dev]"` 刷新 entry_points（editable install 不会自动重新注册）。
7. **测试**（TDD，67 新增用例 → 总数 182）：`test_registry.py`（11，UC-4.1/4.2/4.8：真 entry_points 发现 3/3/2、get 未命中 PLUGIN_NOT_FOUND、list 分组、register 注入、reload 原子替换 + **reload 期间跑一轮不抛异常**、单插件失败隔离、快照不可变）、`test_detectors.py`（25，§6.4 三插件全分支）、`test_suppressors.py`（11，§6.3 两插件 + batch_check）、`test_filter_signals.py`（23，完成标准点名的结构化 matcher 全分支）、`test_plugins_api.py`（2，UC-4.1/4.2 API）；更新 `test_health.py`（`/ready` → 200 ready，db+plugins 均 True）。
