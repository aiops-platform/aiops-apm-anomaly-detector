## 改动点

1. 新增 `src/aiops_apm/models/`（纯类型层，无副作用，契约冻结）：
   - `signal.py` — `MetricSignal` / `LogSignal` / `ChangeSignal` + `Signal` 联合（pydantic v2 依据 `kind: Literal[...]` 默认值自动判别）
   - `anomaly.py` — `MetricAnomaly` / `LogAnomaly` + `Anomaly` 联合；`anomaly_key()` 方法转发 fingerprint
   - `record.py` — `Correlation` / `Verification` / `ProblemRecord`（`@property group_key` 转发 fingerprint.group_key）
   - `config.py` — `DetectorSpec` / `SuppressorSpec` / `CorrelationSpec` / `VerifySpec` / `DomainConfig`（M6 用于 domain_config 写入校验）
   - `fingerprint.py` — `anomaly_key`（sha256[:16]）/ `group_key`（排序无关，`tenant_id:domain:service:<sha256[:12]>`）/ `is_same_group`，去重与 L3 持续性唯一真源
2. 新增 `src/aiops_apm/plugins/base.py` — 插件契约：`Plugin(ABC)`（`name` 字段）+ `Collector.collect` / `Detector.detect` / `Suppressor.check`（+ 默认 `batch_check`）+ `build()` 工厂占位（`raise NotImplementedError`）；`ctx` 用 `Any` 冻结接口形状（`DetectionContext` 属 M5）
3. 测试（TDD 四用例 UC-1.1~1.4）：`tests/test_models.py`（3 用例）、`tests/test_fingerprint.py`（10 用例）、`tests/test_plugins_base.py`（4 用例），共 17 新增用例
4. 修复 M0 遗留测试缺陷：`tests/test_settings.py::test_defaults` 原本依赖无 `.env` 环境，本地 `.env`（`APM_PORT=7070`，README 启动流程创建）会污染默认值断言 → 改为 `Settings(_env_file=None)` 隔离环境文件，断言纯默认值
